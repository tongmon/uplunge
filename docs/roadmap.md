## M2. 한 판 구조

- [ ] 조각 생성기 + 도달 가능성 검증 도구
- [ ] 콤보와 보상, HP 회복, 젬
- [ ] 층 구성 → 층 클리어 → 업그레이드 선택 (업그레이드 6~8종)
- [ ] 구역·층별 물 속도 곡선 (M1 기본 30px/s)
- [ ] 무기 2~3종, 슈트 1종
- [ ] 갈림길 + 격벽실 + 구조 NPC 1종
- [ ] 적 3분류 모두 구현 + 퍼퍼형 적

**통과 기준**: 처음부터 사망 또는 클리어까지 한 판이 완결되고, 판마다 빌드가 달라진다.

## M3. 아트 파이프라인 + 버티컬 슬라이스

**통과 기준**: 스토어 스크린샷과 트레일러를 찍을 수 있는 1구역.

## M4. 콘텐츠
