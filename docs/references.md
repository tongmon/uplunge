### 빌드 다양성

- **업그레이드**: 23종, 전부 최대 1회 획득. 층마다 3개 중 1개 선택, 균등 확률 추첨, 조합 효과 로직 없음 (`scrUpgrades`, `resultRandomizeUg`).
- **총**: 7종. 반동은 대부분 0 (샷건 -1.4, 레이저 -1, 트리플 -0.3, 펀처 -0.5) (`bStatInitLevel1`).
- **총 모듈**: 획득하면 현재 총이 교체됨. 동시에 HP +1 또는 최대 탄약 +2를 받는데, 각 50% 확률이고 HP가 2 이하면 HP 쪽 확률이 6/7로 오름.
- **사이드룸**: 층마다 2~3개. 시간이 멈추는 방, 50% 확률로 상점 (층당 최대 1개).
- **메타 진행**: 누적 젬으로 스타일과 팔레트 해금 (3천/1만/2만/3만). 파워 성장은 없음 (`unlockProgressCheck`).

### 레벨과 카메라

- **구성**: 4구역 × 3층 + 보스. 모든 층이 같은 절차 생성 방(`rmMain`, 480×300000)을 씀.
- **조각**: 9칸 폭 ASCII 조각, 좌우 반전, 연속 중복 금지, 조각 사이 빈 줄. **경로 검증 없음** (`scrBuilder`).
  - 주 조각 수는 구역별로 41 / 29 / 24 / 15개 (`partMain[100]`: `scrLevelPat1:105`, `scrLevelPat2:77`, `scrLevelPat3:70`, `scrLevelPat4:63`). 조각 하나는 9×10칸 (예: `scrLevelPat1:102-104`).
  - 조각마다 50% 확률로 좌우 반전 (`scrBuilder:155`).
  - 조각 안의 확률 칸: `2`는 50% 확률로 벽 (`scrBuilder:211-219`), `3`은 50% 확률로 박스 블록 (`scrBuilder:220-228`), `?`는 25% 확률로 상자 (`scrBuilder:288-293`).
- **카메라**: 160×284. 플레이어 아래 약 166px, 위 약 118px가 보임. 따라가는 비율은 프레임당 1/5 (`camMain`).

### 카메라와 연출

- **목표 위치**: 플레이어 발을 화면 정중앙에. 평소에는 앞 미리 보기가 없음.
  - 깃털 상태에서만 속도 × 0.2만큼 앞을 보여 줌 (`Player.cs:807-901`).
- **따라가기**: `cam += (target - cam) * (1 - 0.01^dt)`. 1초에 99%를 따라잡음.
- **잠금 모드**: 카메라가 지금까지의 최고점보다 180px 넘게 내려가지 않음. 화면 아래로 떨어지면 사망 (`Level.cs:2769-2799`).
- **멈춤(프리즈)**: 대시 0.05초, 범퍼 0.1초, 충전 0.05초, 블록 파괴 0.05초.
- **화면 흔들림**: 대시 방향 0.2초.
- **늘어남·찌그러짐**: 점프 (0.6, 1.4), 착지 최대 (1.6, 0.4).
- **머리카락 색 = 남은 대시 수**: 빨강 1, 분홍 2, 파랑 0, 충전 시 흰색 0.12초.
